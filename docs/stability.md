# 稳定性、晚高峰与测速记录

寻找稳定机场时，可以先查看是否有测试时间、网络运营商、带宽、客户端、测试节点和重复记录。缺少这些条件的最高速度，不能说明当地宽带的晚高峰体验。

[Clashrun 原文](https://clashrun.com/clashjichang/) 附有广州移动、广州电信、广西移动等不同环境的测速图，并说明带宽和测试日期不一致。它们可以用于了解各自条件下的节点差异，不宜放在一起按最高速度排名。本项目没有独立复测这些记录。

短期试用时，可以在相同网络、客户端设置和常用地区下，分别记录白天与晚高峰的连接成功情况、网页和视频体验、长连接中断情况。某一个节点失败，还需要区分本地网络、入口、订阅权限与具体出口的问题。

IEPL、IPLC、直连和中转描述的连接方式不同，但线路名称本身不能证明容量、冗余或故障恢复水平。专线不等于独享带宽，也不等于所有时段零故障。

测速图和套餐速度还可能使用不同单位。1MB/s 约等于 8Mbps，附图里某个高档套餐的测速不能作为入门档突破限速的承诺。查看各服务的测试背景和套餐限制，可参考 [原始文章](https://clashrun.com/clashjichang/)。资料由 Clashrun 内容维护方整理，原文含推广入口。
