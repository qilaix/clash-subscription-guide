# Clash、机场订阅与小火箭选购资料

购买机场订阅前，既要比较付款周期、流量和设备限制，也要确认所用客户端能否导入。下面整理了几类选购与使用资料，方便按设备和问题寻找对应入口。

这些页面包含推广入口，部分内容收录相同服务商。多个页面出现相同介绍，不代表经过独立验证；线路表现、运营时长、评分和解锁范围，都需要回到原始记录与商家条款核对。本目录由 Clashrun 内容维护方整理，不提供独立测评背书。

## 综合机场推荐与订阅选购

[Clashrun 的 Clash 机场选购指南](https://clashrun.com/jichangtuijian/) 整理了购买前的选择条件、不同服务的订阅方案、Clash 导入方式，以及购买后的使用检查。适合已经装好客户端、需要了解下一步如何选订阅的用户。

[机场万事屋](https://www.jcwsw.com/) 将套餐资料、常见代理协议、线路类型和客户端教程放在一起，并提供周期套餐与不限时流量的筛选入口。其部分价格按长期付款和优惠折算，阅读时应同时看一次需要支付的总额。

[稳定机场的 Clash 订阅指南](https://www.wendingjichang.com/) 围绕线路、晚高峰观察、运营维护和主备安排介绍选购方法，并列出服务商参考。文章中的经验、评分与稳定性表述属于该站内容，不能仅凭站名推断已经验证了所有时段的可用性。

[FreeRoad 的 Clash 机场推荐文章](https://freeroad.org/jichangtuijian.html) 介绍订阅选购条件、服务商参考和导入后的检查事项，站内还提供配置、订阅报错与客户端教程入口。

[GitHub 上的 Clash 机场与节点订阅资料](https://github.com/clashjichangtuijian/clash-jichang) 包含套餐和优惠信息、代理协议说明，以及 Clash Verge Rev、v2rayN、v2rayNG、Shadowrocket 等客户端的订阅教程与连接排查。适合希望在一个文档中查看选购条件和软件操作的用户。

## 对照资料时先统一价格口径

月付价格是每个月实际支付的金额；长期套餐的月均价需要先支付对应周期总额；不限时流量包则是一份总流量，不能当作每月重置的额度。旧摘要、优惠变化和更新日期也可能造成不同页面上的数字不一致。

需要进一步比较套餐细目与测速背景，可以查看 [Clashrun 的套餐价格与使用体验对比](https://clashrun.com/clashjichang/)。本资料库另有 [月付预算](monthly-budget.html)、[备用流量包](backup-traffic.html)、[客户端兼容](clash-compatibility.html)、[稳定性与测速](stability.html)、[流媒体及 AI 使用](streaming-ai.html) 的分项说明。
