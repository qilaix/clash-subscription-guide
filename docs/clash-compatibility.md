# Clash 客户端与订阅兼容性

Clash 客户端负责连接和规则分流，机场提供节点和订阅。安装客户端不会自动获得可用节点；官网地址、登录页地址也不能代替个人订阅链接。

购买前应确认具体客户端及版本、订阅格式、节点协议和内核支持情况。只写“支持 Clash”不足以证明每个旧版客户端都能导入所有节点。协议支持会随客户端更新，需以当前客户端文档和实际导入结果为准。

[Clashrun 原文](https://clashrun.com/clashjichang/) 对潮汐列出了 Clash Verge Rev、Clash Meta for Android、Clash Mi 等导入选择，对 SoraLink 列出了 Clash Verge Rev、Clash Mi，对魔法棒和畅网通说明了 Clash 使用方式；引力加速提供第三方客户端订阅说明。具体协议和套餐权限仍要分别确认，不能把同名近似服务的教程直接套用。

原文套餐表可帮助筛选购买条件，导入是否成功还需要在本人客户端验证。出现节点列表后，应确认选中了配置、代理或 VPN 已启动，再手动选择常用节点测试目标应用。能更新订阅与能连接节点，是两个不同的验证步骤。

订阅地址通常包含个人令牌。排查问题时不要把完整地址贴在公开评论、仓库或陌生转换网站。更多导入步骤及相关教程入口见 [Clashrun 原始文章](https://clashrun.com/clashjichang/)。本资料由其内容维护方整理，原文含推广入口。
